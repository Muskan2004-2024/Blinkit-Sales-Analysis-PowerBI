# Blinkit Sales Analysis Dashboard using Power BI

## Project Overview
This project analyzes Blinkit grocery sales data using Microsoft Power BI. The dashboard helps explore sales performance, product categories, outlet characteristics, and customer purchasing patterns.

## Tools & Technologies
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculated measures
- Data Visualization

## Key Performance Indicators
- Total Sales
- Number of Items Sold
- Average Sales
- Average Customer Rating

## Dashboard Features
- Sales analysis by item type
- Fat content analysis
- Outlet size and location analysis
- Outlet establishment year analysis
- Interactive filters and visualizations

## How to Run
1. Download the `.pbix` file.
2. Open it in Microsoft Power BI Desktop.
3. Explore the dashboard and apply filters.
